# v0.3.37 公网入口与图片首屏性能修复

更新日期：2026-09-15

## 问题

- FRP 客户端进程和控制连接仍存在时，公网工作连接可能失效，原监控无法发现这种“假在线”。
- 提示词首页在展示内容前会并发预下载整页原图；弱网或公网出口带宽较低时，页面长时间停留在加载状态。
- 内部图片列表直接使用原始生图文件，单张可能超过 1 MB。

## 修复

- Windows 每分钟同时探测本机页面和公网页面；仅在本机正常且公网连续失败时重启 FRP，不触碰 Docker、数据库或任务容器。
- 提示词 API 返回后立即渲染，卡片图片按视口懒加载。
- `/uploads/` 卡片图通过 Next.js 生成 640px 预览并长期缓存，详情页继续展示原图。

## 发布边界

- FRP 守护脚本独立安装，不依赖 Web 镜像发布。
- Web 发布只替换主前端与 Hermes 前端。
- 核心后端、AI Worker、Hermes API、Hermes Worker、PostgreSQL、Redis 和 MinIO 不得重启。
