## 本次解决的问题与保留边界

1. PostgreSQL 外键名超过 63 字符：使用 `op.f` 让方言稳定截断，同名创建/回退，SQLite 保持旧名。
2. Docker 内部图片地址无法被浏览器解析：只在工作流响应序列化转换成图和母图地址。
3. 网页刷新前已缓存的旧任务详情可能仍携带旧图片 URL；**重新加载网页**后即使用修复地址。
4. 已知创建时间显示少 8 小时问题仍在，按约定没有顺带修改时区或历史数据。
5. 本次是一次真实上线链路验收，不是 40 篇压力测试，也不是长期零故障保证；没有开启每日任务。
