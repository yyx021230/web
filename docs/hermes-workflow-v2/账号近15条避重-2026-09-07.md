# 账号最近15条内容：宽松避重接入

## 用户口径

选择账号不只是分配篇数：读取该账号最近15条内容，避开过度同质化。普通相似可以接受，不要求所有文章完全不同，不为去重破坏母文复刻结构。

## 已确认的旧问题

- 旧实现按最近14天调用全账号数据看板，再在本地筛选账号。账号更新频率较低时，即使数据库有很多帖子，也会读成0条。
- 喂给 Hermes 的只有12个标题、10个开头；选母文最多参考24条，口径不一致。
- 选母文一直追求最低相似度，且扩池判断只看批内重复，未把“与本账号历史高度雷同”作为明确扩池条件。

## 本次实现

1. 使用现有 `GET /xhs/account-notes?page=1&limit=15&environment_id=…&status=active`，按发布时间降序读取每个选定账号的15条有效已同步帖子，不传日期窗口。账号间最多4路并发；相同账号只查一次，不加载全站看板。
2. 响应如果混入其他账号、缺失列表或总数明显不完整，明确报读取错误，不把接口异常当作“账号没有历史”。空账号/不足15条是正常情况；缺正文只使用已知标题，不虚构正文，也不以更老的帖子替换最近15条中的缺失项。
3. 新任务保存 `account_history.snapshot.json`，记录账号ID、15条ID/标题/完整正文、最新发布时间、缺正文数量和读取时间；同一批次重试使用冻结内容。旧任务不会被重新生成或改写。
4. 母文选择使用同账号最近15条完整文本的结构相似度：车型/数字归一，去除话题、短留资句和装饰标点，比较全文而非前几行。4-gram Jaccard 0.85只是代码的高相似筛选边界，不是自然语言语义百分比。
5. 只有高度雷同才优先避让。普通相似候选继续随机选，不再一味挑差异最大的文案；随机窗口无合适项只扩池一次，仍无解则选相对合适的并记录降级，不无限循环、不增加付费重生链。
6. Hermes收到该账号15条完整标题/正文，只用于避重，不作为目标车型、政策、账号人设来源；不能为了去重硬改母文。生成后保留最相近历史帖子ID、分数和覆盖条数，高相似提示为非阻断审核提醒，不新增严格语义禁用词库。
7. 交付/回填保留 `account_history` 与 `account_repetition`；现有审核流程、账号归属和发布权限不变。此次是文本结构避重，不冒充图片像素/视觉相似检测。

- 覆盖：每账号各15条、跨月旧帖可读、日期/时区排序、缺正文不回填老帖、账号隔离、异常不伪装为空、全文高度重复识别、话题/CTA不误判、普通相似仍随机、高度雷同扩池及有限降级。
- 首次线上只读查询：账号42「云先派懂车社」总计160条，最近15条正文全部存在，最新已同步发布时间2026-07-30；账号27「云特曼」总计423条，最近15条有12条正文，最新已同步发布时间2026-09-03。旧14天窗口会漏掉账号42。
