# Hermes 工作流内页优化 · 2026-09-07

实际项目：`/Users/yyx/ztqc/web`。本轮仅调整前端，不修改生成策略、账号数据、政策、定时任务或历史图文，不发起生产、审核通过或发布操作。

## 已落实

- 保留用户认可的工作流广场及卡面，本轮使用 frontend-design 技能统一内页间距、字体、配色与卡片层级。
- 参数区使用持续可见的字段标签，账号下拉可分别设置篇数，混合篇数显示“分别设置”。车型继续多选；全量政策入口不依赖车型选择。
- 精准单篇保留独立的文案类型、图片类型和真实库内案例入口，没有把类型选择改成随机。
- 从历史任务链接进入时默认收起参数；下发成功后仍自动收起，给历史图文留出空间。
- 单个账号仅一篇时，桌面采用左图右文；多篇为独立图文卡片；窄屏自动单列。原图完整等比展示，不裁切图片上的文字。
- 标题、正文和末尾话题均保留；卡片可展开全文，并复制完整标题、正文、emoji 和话题。
- 任务顶部显示任务编号、名称与状态，卡片显示母文、母图编号。筛选栏保留常用搜索、状态与账号，来源和日期放在“筛选”内。
- 文案对照展示已保存的账号参考快照摘要及非阻断的高度相似提醒。旧记录无快照时明确标注未记录，不虚构“已检查15条”。
- 图片加载失败有可读提示；生成失败或取消的帖子不再显示“等待创作完成”。

## 验证

- 在实际项目运行 TypeScript 无输出检查，通过。
- 7 个新增组件交互测试 + 7 个现有 API 合约测试，共 14 个通过。生产、审核接口在单元测试中均为 mock，不提交真实任务。
- 浏览器检查现有单篇任务和任务 #3 的五篇卡片，验证筛选、原文对照、滚动和账号独立篇数（3 + 5 = 8）。
- 检查 1440px 桌面、默认约 800px 和 390px 窄屏布局；工作流区域无横向溢出，临时视口已恢复。390px 下全站顶部品牌栏原有换行问题不属于本轮工作流组件改动。
- ESLint 未能执行：实际项目没有 ESLint 配置文件；没有为此新增全站配置。未执行生产构建。

## 保持不变 / 不能据此声称解决

- 既有图文的内容质量问题未在本轮修改；界面“待审核”不等同于人工合格。
- 账号历史从生产时的已同步内容读取，前端只是展示已有证据，不触发实时平台采集。
- 未实现新的自动发布接口，未启动或修改每日定时任务。
- 用户尚未批准的“文案逐段替换”生成机制不在本轮范围内。
