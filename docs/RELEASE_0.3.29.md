# v0.3.29 首页与工作台稳定性修复

更新日期：2026-09-14

## 修复范围

- 首页在展示卡片前预取图片尺寸，为瀑布流预留稳定比例；图片加载时不再触发列重排和视觉滚动。
- 首页卡片入场只保留短促透明度过渡，不再使用会造成整体位移感的纵向动画。
- Hermes 批量和单篇工作流只读取内部提示词素材，并按接口总数自动分页，不因首页外部素材超过 1000 条而终止生产。
- 普通用户工作台继续只展示本人创建或分配给本人的内容；管理员仍通过独立管理接口查看全量。
- 已结束或失败的任务支持由创建者删除；排队或生产中的任务拒绝删除。
- 核心发布门禁纳入 Hermes 活跃任务，避免工作台生产过程中切换核心服务。

## 发布边界

- 不新增数据库迁移，不修改提示词、文案、图片或历史工作流数据。
- 核心前端和后端通过 `deploy-to-windows.sh` 发布。
- Hermes Worker 通过 `deploy-hermes-worker-to-windows.sh` 独立发布；只替换 Worker，Hermes API、数据库和其他服务保持不变。
- 两步发布都必须在任务门禁通过后执行；失败时恢复原镜像与 Compose 配置。

## 验收

- 首页刷新时卡片位置稳定，图片在预留区域内逐步显示。
- 两个工作流的运行时素材查询全部为 `internal`，返回数量与接口总数一致。
- 不同普通用户无法查看或删除对方的手工任务。
- 失败任务可删除，运行中的任务不可删除。
- 核心版本、Hermes Worker 镜像、健康状态和发布回执一致。
