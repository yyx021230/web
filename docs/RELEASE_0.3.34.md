# v0.3.34 首页相关推荐修复

更新日期：2026-09-15

首页详情的“更多相关内容”不再从当前瀑布流中按同一大分类直接截取。候选数据改为按分类一次性读取并缓存，再依据标题及中英文提示词中的主体、产品、场景和材质关键词计算相关度，同时排除当前素材、重复图片和完全重复文案。

发布范围只有主前端和 Hermes 前端；核心后端、AI 生图 Worker、Hermes API、Hermes Worker 和数据服务均不得重启。

发布后检查：

- 产品与品牌素材应优先推荐同类产品视觉，不得仅按入库顺序推荐。
- 人像摄影素材应优先推荐人物摄影，不得混入同分类下的无关主题。
- 连续点击相关推荐时使用分类缓存，不重复请求完整候选池。
- 其他服务容器 ID 和启动时间与发布前保持一致。
