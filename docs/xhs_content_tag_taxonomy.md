# 小红书内容两层标签体系

生成时间：2026-06-23

## 数据依据

- 分析范围：`backend/dev.db` 中 `xhs_account_notes` 表。
- 有标题且有正文的笔记：3042 条。
- 内容时间范围：2026-03-25 至 2026-06-05。
- 这批内容的主体不是泛汽车媒体内容，而是汽车销售线索内容，核心集中在行情、政策、报价、补贴、避坑和本地承接。
- 高频正文信号：城市 2776、补贴 2316、政策 2129、福利 1995、本地 1586、报价 1459、权益 1428、配置 1321、落地价 1304、置换 1198、避坑 1169。

## 设计原则

1. 每篇帖子只打一个一级标签和一个二级标签。
2. 一级标签按“用户看到这篇内容时被承诺解决的主问题”划分，不按品牌、车型、城市、投放方式或 CTA 划分。
3. 二级标签必须属于对应一级标签，不能跨一级借用。
4. 品牌、车型、城市、本地报价、CTA、投放/自然流、效果指标是辅助字段，不进入这套主标签体系。
5. 遇到多个信号时，优先看标题和正文前 3 行，其次看正文主体，最后看 CTA。
6. 如果只是 CTA 里出现“城市、报价、补贴”，但标题和正文主线不是报价/政策，不要因此改主标签。

## 冲突判定优先级

当一篇帖子同时命中多个方向，按下面顺序选择主标签：

1. 内幕确认主线：标题/正文主钩子是“内部、刚通知、敲定、实锤、销冠、店长、离职”等信息来源或确认感。
2. 避坑提醒主线：主钩子是“别急、再等等、别乱、听劝、避坑、别买贵、防坑”。
3. 行情报价主线：主承诺是“行情变化、真实报价、落地价、好价、价格窗口”。
4. 政策权益主线：主承诺是“新政、福利、补贴、置换、金融、月供、权益包”。
5. 购车服务主线：主承诺是“帮提、团购、成团、砍价、试驾、提车、验车、上牌”。
6. 选车导购主线：主承诺是“怎么选、对比、配置、预算、首购、家用通勤选择”。
7. 产品价值主线：主承诺是车辆产品力种草，如续航、智驾、空间、舒适、动力。
8. 新车动态主线：主承诺是新车上市、预售、改款、品牌事件。

## 建议辅助字段

为避免主标签重叠，建议 AI 打标时同时输出这些辅助字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| brand | 品牌 | 比亚迪、零跑、理想 |
| model | 车型 | 元 UP、C11、L6 |
| city_signal | 是否出现城市/本地口径 | true/false |
| cta_type | 承接动作 | 私信报价、城市车型、试驾预约、领取清单 |
| price_signal | 是否出现价格/报价/落地价 | true/false |
| policy_signal | 是否出现政策/补贴/权益 | true/false |
| risk_signal | 是否出现避坑/别急/别买贵 | true/false |
| confidence | 打标置信度 | 0.00-1.00 |
