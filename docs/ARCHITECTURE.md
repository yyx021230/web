# AI Creative Studio — 架构文档

## 1. 系统概览

AI Creative Studio 是一个集在线图形编辑、AI 生图和工作流编排于一体的创意工作台。

### 核心功能
1. **Fabric.js 编辑器** — 对标 vue-fabric-editor，支持图形绘制、图层管理、导入导出
2. **AI 生图模块** — 支持 Seedream 模型，预留 Midjourney / Stable Diffusion 扩展
3. **Dify 工作流集成** — 可添加多个 Dify 实例，管理工作流配置，支持阻塞和流式运行

## 3. 数据流

### 3.1 AI 生图流程
```
用户输入提示词 → 前端选择模型 → 调用 /api/v1/ai-image/generate
→ 后端 AIImageService → AIModelAdapter (Seedream)
→ 外部 AI API → 返回图片 URL → 前端展示 → 可选插入画布
```

### 3.2 Dify 工作流运行流程
```
用户选择工作流 → 填写输入参数 → 点击运行
→ 后端 DifyWorkflowService → 获取对应 DifyClient
→ 调用 Dify API (POST /v1/workflows/run)
→ SSE 流式返回 → 前端实时更新进度
→ 运行完成 → 保存日志 → 可选将结果插入画布
```

## 4. 扩展性设计

### 4.1 AI 模型扩展
新增模型三步：
1. 在 `backend/app/adapters/ai_model/` 创建适配器文件
2. 实现 `AIModelAdapter` 接口
3. 在 `__init__.py` 注册到 `model_registry`

### 4.2 Dify 多实例支持
- 每个 Dify 实例独立配置 (base_url, api_key)
- 工作流绑定到具体实例
- 支持设置默认实例

### 4.3 存储扩展
- 本地存储: `LocalStorageAdapter`
- S3/MinIO: `S3StorageAdapter` (预留)
- 通过配置切换存储后端

## 5. 安全考虑
- JWT 认证保护 API
- Dify API Key 加密存储
- CORS 配置限制来源
- 输入验证 (Pydantic + Zod)
- 文件上传大小限制

## 6. 性能优化
- 前端图片懒加载
- 后端数据库连接池
- Redis 缓存模板和素材列表
- SSE 流式响应减少内存占用
- Fabric.js 按需渲染
