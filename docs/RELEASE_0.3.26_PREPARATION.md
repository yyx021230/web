## 回滚

- 核心发布失败由 `Deploy-Release.ps1` 自动恢复上一不可变镜像和发布前数据库备份。
- 素材安装在数据库单事务中执行；安装前校验失败不会改数据库。
- 素材安装后若业务验收失败，使用本次核心发布记录的发布前 PostgreSQL 备份恢复；新增图片目录可保留，不影响旧数据引用。
