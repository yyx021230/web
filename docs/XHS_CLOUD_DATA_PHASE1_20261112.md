## 实现链路

```text
原创作者中心手动或定时同步入口
  -> 根据配置选择 browser 或 phone_cloud
  -> 云手机客户端只读查询已有批次及逐账号分页
  -> 当前授权范围、核验绑定、完整性、日期及字段校验
  -> 同账号标题/北京时间日期匹配或建待补记录
  -> 原始观察、帖子更新和应用回执事务提交
  -> 原主页同步补ID与链接 -> 原详情同步补正文与配图
```

复用现有账户数据定时任务的执行时间和开关，本阶段没有新增每5分钟轮询，也不修改云手机现有02:00计划。当前查询有界检查最近5个批次，优先最新账号观察，最多100页/批次、10账号/页，远端查询总预算180秒。最新失败/排队不伪装为旧成功，未找到或过期明确失败。该范围不是全历史批次归档或全历史帖子补采；历史归档、持续游标消费和专用轮询留后续阶段。

一次任务不要求整个手机批次全部成功，按单账号决定是否合并。失败、跳过、不完整、身份不明、同名同日冲突留在回执；排队/执行中尚非不可变结果，不创建最终观察回执，后续读取同一任务完成结果。失败不会触发手机或浏览器重抓。

## 身份和数据规则

- 开放API的 `platform_binding_snapshot` 不是实际登录身份证明。本候选要求后台私有配置列出人工核验过的 `xhs_id/device_id/app_slot/verified_at`，拒绝错号事件、双遍未证、设备或槽位变化及核验之前的历史快照。空名单默认不导入；不自动查名、猜昵称或创建账号。
- 只更新手机确实返回的观看、点赞、评论，明确0可更新，null不更新。不清空旧正文、配图、ID、收藏、分享或曝光；旧观察不能覆盖较新字段。同字段来源和精度单独记录，手机数值标为 displayed 或 approximate，不伪装成精确值。
- 手机日期以北京时间零点换算成现有UTC字段，并标 `published_at_precision=date`，不假装知道具体时分秒。主页或人工导表补到精确时间时升级为 second，匹配到原记录，不新增同一帖。
- 同标题同日多帖、180字符截断、同日旧标题消失等无法唯一确定时，整个账号观察隔离，不强行按序号或临时封面指纹合并。暂不提供人工帖子归并界面。
- `metric_sources=null` 兼容历史整条主同步保护，手机新记录改为按字段保护；云登仍可补手机缺失的收藏/分享等字段。浏览器网络请求返回后重新读取当前记录，避免用请求前旧状态覆盖刚入库的手机数据。
- 成功空列表不删除历史、不批量标下线。近30天是发布窗口内帖子的累计指标，不能作为当日新增互动求和。
- 唯一观察键为客户端、run_id、item_id；相同键不同摘要拒绝覆盖。使用环境和笔记行锁、唯一约束及事务回执，业务应用失败回滚该账号修改，保留原始观察供重放。
- 账号列表仍按现有用户/部门权限解析，不能通过上游结果改负责人。纯云手机账号可进入主数据接入，但未扩展现有云登自动补充的账号筛选范围；其主页绑定与补充需另行核对，不能宣称已完成独立采集端。

## 配置与接口

默认 `XHS_CREATOR_SYNC_SOURCE=browser`。配置完并通过验收后才显式改为 `phone_cloud`。所需后端配置：

| 配置 | 含义 |
|---|---|
| `PHONE_CLOUD_XHS_DATA_BASE_URL` | 平台根地址，不含API路径、凭据或查询串 |
| `PHONE_CLOUD_XHS_DATA_CLIENT_ID` | 有权读取现有日采批次的客户端身份 |
| `PHONE_CLOUD_XHS_DATA_SECRET` | 后端HMAC密钥，不写入前端、文档或日志 |
| `PHONE_CLOUD_XHS_DATA_HTTP_ORIGINS` | 默认空；确需无TLS入口时逐个显式批准，不自动从HTTPS降级 |
| `PHONE_CLOUD_XHS_VERIFIED_BINDINGS` | JSON数组，含上述4个核验字段；不混用短信或发布白名单 |
| `PHONE_CLOUD_XHS_DATA_MAX_AGE_HOURS` | 默认48小时；可配置1至168小时，过期不报新鲜成功 |

客户端只实现 `/api/v1/open/xhs-data/batches` 及单批结果 GET。HMAC签原始查询串、每请求新Nonce；拒绝重定向、异常分页、重复账号、总数不一致、超大响应和非200，不在错误中回显上游正文。

新增管理接口均复用现有 `require_admin`：`GET /api/v1/admin/xhs/cloud-imports` 支持skip/limit和账号过滤，只返回回执，不暴露原始payload；`POST /api/v1/admin/xhs/cloud-imports/{id}/retry` 只重放已留存观察，不创建或查询手机任务。原账号帖子API附带字段来源与时间精度，运营洞察附带缺失指标覆盖信息；本轮没有新增前端来源选择器、缺失指标横幅或新的图表口径。
